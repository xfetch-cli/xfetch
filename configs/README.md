# Internal Config Templates

<p>
  This directory contains the minimal configuration templates that the
  <strong>xfetch</strong> core needs at build time and install time.
</p>

<ul>
  <li><code>config.jsonc</code>: default config installed by the shell and PowerShell installers.</li>
  <li><code>layout_pacman_full.jsonc</code>: curated template used by <code>xfetch --gen-config</code>.</li>
</ul>

<p>
  The public catalog of shareable presets now lives in
  <a href="https://github.com/xfetch-cli/configs">xfetch-cli/configs</a>.
</p>
